# IBRA CLEAN UP

محلل المساحة ومنظف الملفات المؤقتة والكاش لويندوز — يكشف شنو ماكل مساحة القرص C وخصوصاً مجلد `C:\Users`، يشرح كل مجلد شنو هو وهل حذفه آمن، ويخليك تحذف بالتحديد بعد ما تشوف الملفات.

**برمجة وتطوير ابراهيم الخزرجي** — [موقع تطبيقاتي](https://ibraprogram.netlify.app/) • [تيليكرام](https://t.me/ibraprogram) • تيك توك: ibraprogram

## المميزات
- **محلل المساحة**: فحص سريع لأي مجلد أو قرص (افتراضياً `C:\Users`) مع خريطة مرئية للأحجام، تنقل بين المجلدات، ملفات كل مجلد، وتفاصيل كاملة (الحجم، عدد الملفات، آخر تعديل).
- **شرح لكل مجلد**: قاعدة معرفة تقول شنو هذا المجلد (AppData، كاش كروم، مشاريع كاب كات، نسخ الآيفون...) وتصنيفه: آمن / راجعه / لا تحذفه / نظام.
- **المؤقتة والكاش**: Temp، كاش المتصفحات، كرت الشاشة، تقارير الأعطال، تحديثات ويندوز، سلة المحذوفات، تيليكرام، ديسكورد، npm/pip/Gradle...
- **تحميلات تلقائية بدون علمك**: نموذج الذكاء حق كروم (Gemini Nano) مع زر **منع التحميل التلقائي**، نماذج Edge، نسخ الآيفون الاحتياطية (iTunes / Apple Devices)، تحديثات IPSW، ملفات 3uTools، كاش أوفيس.
- **المونتاج والتصميم**: كاش ومسودات CapCut (كل مشروع لوحده بحجمه وتاريخه)، كاش Adobe (بريمير، أفتر، فوتوشوب، Camera Raw) والحفظ التلقائي والمعاينات.
- **الملفات الكبيرة**: أكبر 1500 ملف مع فلترة حسب النوع والحجم والعمر والبحث.
- **اقتراحات ذكية**: node_modules والبيئات البرمجية القديمة، ملفات ISO والمثبتات الضخمة، أكبر مجلدات AppData.
- **حذف آمن**: تأكيد يعرض كل العناصر، اختيار سلة المحذوفات أو حذف نهائي، حماية مجلدات النظام، تخطي الاختصارات والـ Junction، وسجل لكل عملية حذف.
- **مخلفات التثبيت (Windows Installer Cleaner)**: يفحص `C:\Windows\Installer` بمحرك مستقل — Windows Installer API (ProductsEx / PatchesEx عبر كائن COM الرسمي، بكل السياقات والحسابات، 32 و64 بت) + تحقق ثاني من سجل الويندوز. لا يستخدم Win32_Product. التصنيف: مستخدمة / يتيمة محتملة / مستثناة / غير معروفة. أي فحص ناقص أو تثبيت جاري يوقف التنظيف. إعادة تحقق قبل كل نقل أو حذف. النقل للنسخة الاحتياطية هو الافتراضي (SHA-256، سجل journal يتحمل الانقطاع، حفظ الصلاحيات ACL والتواريخ، استعادة ملف أو الكل، لا كتابة فوق ملف بدون موافقة). تصدير التقرير CSV/HTML.
- **ستايلات**: زجاج أحمر وأسود، زجاج أبيض وأحمر، زجاج أبيض، زجاج شفاف (Acrylic على ويندوز 11)، ليلي، أبيض، وحسب ويندوز.
- **سلايد IBRA STORE** بالرئيسية لآخر البرامج والألعاب، يرث ألوان وخط التطبيق (‎--ibra-accent‎ أو الثابت ACCENT بملف `store-slider.js`).
- **تحديث داخلي**: يتحقق من المتجر، يحمل التحديث ويتأكد إنه ملف تثبيت صالح، وينصبه فوق النسخة الحالية ويرجع يشغل البرنامج — كل خطوة بموافقة المستخدم.
- فتح أي مجلد مباشرة بالمستكشف، نسخ المسار، تشغيل كمسؤول، عربي وإنكليزي.

## التشغيل والبناء
```bash
npm install
npm start          # تشغيل للتجربة
npm run test:scan  # اختبار محرك الفحص
node scripts/test-msi.js  # اختبار محرك مخلفات التثبيت (نقل، استعادة، انقطاع)
npm run dist       # يبني dist/IBRA-CLEAN-UP-Setup-<version>.exe
```
## نشر إصدار جديد
1. غيّر `version` بـ `package.json` وارفع التعديل.
2. أضف سطر الإصدار لـ `releases/versions.json` (الرقم + الـ commit + `"latest": true`، وخلي الإصدار القديم `false`) واكتب ملاحظاته بـ `releases/notes/<الإصدار>.md`.
3. ارفع على `main` — GitHub يبني ملف التثبيت من نفس الـ commit وينشره بصفحة الإصدارات مع حجمه وبصمته SHA-256. الإصدارات المنشورة مسبقاً ما تنعاد.

## التحديث الداخلي من IBRA STORE
البرنامج يقرأ `https://ibraprogram.netlify.app/api/apps` ويدور على العنصر اللي `slug` مالته `ibra-clean-up`. حتى يشتغل التحديث المباشر، خلي بالعنصر:
- `version`: مثل `"1.1.0"`
- رابط ملف التثبيت `.exe` بأي حقل تحميل لويندوز (مثل `downloads: [{ "platform": "Windows", "url": "https://.../IBRA-CLEAN-UP-Setup-1.1.0.exe" }]`)
- اختياري: `sha256` لبصمة الملف و `changelog` للجديد.
إذا ماكو رابط مباشر (مثل كوكل درايف بملف كبير)، البرنامج يعرض فتح صفحة البرنامج بالمتجر بدل التحميل الداخلي.
