# IBRA CLEAN UP

محلل المساحة ومنظف الملفات المؤقتة والكاش لويندوز — يكشف شنو ماكل مساحة القرص C وخصوصاً مجلد `C:\Users`، يشرح كل مجلد شنو هو وهل حذفه آمن، ويخليك تحذف بالتحديد بعد ما تشوف الملفات.

**برمجة وتطوير ابراهيم الخزرجي** — [موقع تطبيقاتي](https://ibraprogram.netlify.app/) • [تيليكرام](https://t.me/ibraprogram) • تيك توك: ibraprogram

## المميزات
- **محلل المساحة**: فحص سريع لأي مجلد أو قرص (افتراضياً `C:\Users`) مع خريطة مرئية للأحجام، تنقل بين المجلدات، ملفات كل مجلد، وتفاصيل كاملة (الحجم، عدد الملفات، آخر تعديل).
- **شرح لكل مجلد**: قاعدة معرفة تقول شنو هذا المجلد (AppData، كاش كروم، مشاريع كاب كات، نسخ الآيفون...) وتصنيفه: آمن / راجعه / لا تحذفه / نظام.
- **المؤقتة والكاش**: Temp، كاش المتصفحات، كرت الشاشة، تقارير الأعطال، تحديثات ويندوز، سلة المحذوفات، تيليكرام، ديسكورد، npm/pip/Gradle...
- **تحميلات تلقائية بدون علمك**: نموذج الذكاء حق كروم (Gemini Nano) مع زر **منع التحميل التلقائي**، نماذج Edge، نسخ الآيفون الاحتياطية (iTunes / Apple Devices)، تحديثات IPSW، ملفات 3uTools، كاش أوفيس.
- **المونتاج والتصميم**: كاش ومسودات CapCut (كل مشروع لوحده بحجمه وتاريخه)، كاش Adobe (بريمير، أفتر، فوتوشوب، Camera Raw) والحفظ التلقائي والمعاينات.
- **الملفات الكبيرة**: أكبر 1500 ملف مع فلترة حسب النوع والحجم والعمر والبحث.
- **اقتراحات ذكية**: node_modules والبيئات البرمجية القديمة، ملفات ISO والمثبتات الضخمة، أكبر مجلدات AppData.
- **حذف آمن**: تأكيد يعرض كل العناصر، اختيار سلة المحذوفات أو حذف نهائي، حماية مجلدات النظام، تخطي الاختصارات والـ Junction، وسجل لكل عملية حذف.
- فتح أي مجلد مباشرة بالمستكشف، نسخ المسار، تشغيل كمسؤول، عربي وإنكليزي.

## التشغيل والبناء
```bash
npm install
npm start          # تشغيل للتجربة
npm run dist       # يبني dist/IBRA-CLEAN-UP-Setup-<version>.exe
```
على GitHub: ارفع tag مثل `v1.0.0` وراح يتبنى ملف التثبيت تلقائياً ويتنشر بالـ Releases (أو شغّل الـ workflow يدوياً من تبويب Actions).
