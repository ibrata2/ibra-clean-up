## IBRA CLEAN UP 1.0.0 — أول إصدار

محلل المساحة ومنظف الكاش لويندوز.

### المميزات
- **محلل المساحة:** يفحص `C:\Users` أو أي مجلد أو قرص، مع خريطة مرئية للأحجام وتفاصيل كل مجلد.
- **شرح لكل مجلد:** آمن للحذف / راجعه / لا تحذفه / نظام.
- **المؤقتة والكاش:** Temp، كاش المتصفحات وكرت الشاشة، تقارير الأعطال، تحديثات ويندوز، سلة المحذوفات.
- **تحميلات بدون علمك:** نموذج الذكاء حق كروم مع زر منع التحميل، نسخ الآيفون، ملفات IPSW و 3uTools.
- **المونتاج والتصميم:** كاش ومسودات كاب كات (كل مشروع لوحده)، كاش أدوبي.
- **الملفات الكبيرة والاقتراحات الذكية** (node_modules، ملفات ISO والمثبتات).
- **حذف آمن:** سلة المحذوفات أو نهائي، حماية مجلدات النظام، سجل الحذف.
- عربي وإنكليزي، أيقونة وألوان ذهبي/أحمر/أسود.
