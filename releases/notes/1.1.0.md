## IBRA CLEAN UP 1.1.0

### الجديد
- **مخلفات تثبيت البرامج (Windows Installer Cleaner):** فحص `C:\Windows\Installer` بالتحقق من Windows Installer API وسجل الويندوز، تصنيف (مستخدمة / يتيمة محتملة / مستثناة / غير معروفة)، نقل للنسخة الاحتياطية مع بصمة SHA-256 واستعادة، وتصدير التقرير CSV/HTML.
- **7 ستايلات:** زجاج أحمر وأسود، زجاج أبيض وأحمر، زجاج أبيض، زجاج شفاف، ليلي، أبيض، حسب ويندوز.
- **صفحة الإعدادات:** الستايل، اللغة، مجلد النسخ الاحتياطي.
- **سلايد IBRA STORE** بالرئيسية لآخر البرامج والألعاب.
- **تحديث داخلي** من داخل البرنامج بموافقة المستخدم.
